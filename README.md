## 一、当前在做什么

**一件事：单策略 → 先跑出正期望 → 再谈组合 → 最后谈仓位。**

次序不能换，原因一句话：

- 组合是 `E[组合] = Σ wᵢ · E[腿ᵢ]` —— **两个正期望的腿相加才可能正**，
  负的加负的只会更负（加品种、加策略都只是降方差，不造收益）。
- 仓位管理只改**方差 / 回撤**，不改**期望符号**。

**当前这一步**：单品种 · 单逻辑 · 30 分钟 · 甲醇 MA。

| 项 | 值 |
|---|---|
| 策略 | 通道突破（唐奇安 / 海龟原型） |
| 一句话逻辑 | 突破前 5 个交易日最高价做多 / 跌破最低价做空；反向破位离场（不反手）；亏 1 个日线 ATR 止损 |
| 品种 | 甲醇 MA |
| 周期 | 30 分钟 |
| 手数 | 固定 1 手（**仓位管理是后面的事，这一轮不掺进来**） |
| 运行入口 | `策略/04_通道突破/回测/甲醇/回测.bat`（或根目录 `跑回测.bat` 菜单） |

**只看三个数**：总盈亏 / 最大回撤 / 交易笔数。
（这个样本长度上夏普、年化、t 值**测不出真假**，看了只会误导 —— 这是测量问题，不是对策略的判决。）

**只有两条不许碰的线**（用户 2026-09-16 规则）：

1. 禁未来函数 —— 信号只用已收盘 K 线，下一根开盘成交；
2. 先有逻辑再写代码 —— 不叠加过滤、不遍历参数择优、每次只改一处。

```
跑回测.bat       ★ 双击入口（弹出菜单）

                  01_双均线 / 02_均线排列⛔ / 03_均值回归 / 04_通道突破 / 05_摆动线
                  每个策略下：_档案.md + 回测/<品种>/ + 模拟盘/<品种>/

工具/           12 个常用脚本 + _数据/ _账本/ _输出/
回测结果/       回测报告落这里（单轨，同名覆盖，只留最新 + 汇总页）

```

> **想改买卖逻辑**？改 `lib/engine.py` 里对应的那个函数（回测与模拟盘共用同一份）。
> **想换品种参数**？改 `config_symbols.py` 那两张表。
> **想加一个新策略**？在 `策略/` 下建一个编号目录，照现有策略抄。
