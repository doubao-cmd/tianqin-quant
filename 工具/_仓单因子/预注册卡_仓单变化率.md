## 一、因子定义

```
receipt_t        = 第 t 日某品种「注册仓单」总量（品种级日度，跨交割库聚合）
rc_t             = receipt_t / receipt_{t-K} − 1        ← 用 t−1 及更早，零未来函数
方向（t 开盘成交，用 rc_{t-1} 判定）：
    rc_{t-1} <  −THRESH  → 开多（注册仓单骤降 = 可交割货紧 = 近月走强）
    rc_{t-1} >  +THRESH  → 开空（注册仓单激增 = 现货抛压/套保进场 = 价格承压）
    |rc_{t-1}| ≤ THRESH  → 空仓
持仓：触发后持有 HOLD 交易日，到期下一开盘平仓；平仓日若仍满足同向信号则续持。
```

**为什么可能有效（逻辑构成）**：
1. **交割库库存是现货供给的硬指标**：注册仓单（可交割实物）的净变化，比价格更"慢"、更
   难被资金短期操纵，反映真实的套保盘进场 / 提货转现货压力。
2. **供给侧慢变量，与价格动量/均线低相关**：你已用 06/08 证伪价格形态类因子，仓单是
   **维度升级**（市场行为 → 现货供给），提供分散化，且散户极少下场（数据散、要聚合、要懂
   注销语义），不拥挤。
3. **领域知识可变现**：你做过甲醇/乙二醇/豆粕，懂现货端"仓单为什么反映紧俏"，能正确解读
   信号、选适用品种——这是护城河。

**⚠️ 注销语义陷阱（本卡核心设计决策，必须照此实现）**：
仓单分「注册仓单」（在可交割池内）与「注销仓单」（移出可交割池，可能转现货或日后重新注册）。
**注销 ≠ 供给消失**。因子输入**只用「注册仓单」净变化**，**严禁混入注销仓单总量**——
否则会出现"注销激增误判为货紧做多、实际只是转现货"的反向错误。这是大多数人把仓单因子做反的地方。

## 二、参数（一次定死，不许调）

| 参数 | 值 | 依据 |
|---|---|---|
| `K_CHANGE` | **20** 交易日 | 仓单变化率回看窗（约 1 个月），慢因子的标准尺度 |
| `THRESH` | **±10%** | 固定启发式（20 日注册仓单变化超 ±10% 为显著供给变动），**非优化、非扫描** |
| `HOLD` | **20** 交易日 | 持仓期，到期待下一开盘平仓；续持规则见定义 |
| 成交 | t−1 收盘算 rc → **t 开盘成交** | 零未来函数；仓单日报盘后发布，用于 t+1 信号 |
| 手数夹 | **[1, 8]** | 沿用本仓口径 |
| 滑点 | 1 跳 | 沿用 |
| 手续费 | `config_symbols.COST` | 沿用 |
| 止损 | **无**（出场仅 HOLD 到期/续持判定）| 加止损属逻辑改动，须另立卡 |
| 品种池 | **9 个固定**：MA / M / RB / V / JD / JM / P / RU / SR | 沿用 2026-10-10 拍板：换窗口不换品种 |

⚠️ 全部取固定启发式/沿用值，**不扫描阈值、不遍历 K、不按品种单独标定**（那会触发规则 2/4 禁区）。

## 五、硬校验（跑前定死，任一失败结果作废）

| # | 校验 | 判据 |
|---|---|---|
| 1 | 方向一致性 | rc<−THRESH 必持多、rc>+THRESH 必持空（逐笔断言）|
| 2 | 成交纪律 | 仅信号触发日(next open)开仓；HOLD 后退出；不日内调仓 |
| 3 | 账目恒等 | `INIT + Σpnl == final_equity`（容差 1 元）|
| 4 | 无未来函数 | 因子只用 t−1 及更早的仓单+价格；成交 t 开盘；**不得用 t 日盘后发布的仓单解释 t 日及之前收益** |

| 6 | 样本量 | IS 开仓笔数 ≥ 10（否则无信号收档）|
| 7 | 权益非负 | 逐日权益 > 0 |
| 8 | **仓单语义校验** | 因子输入必须 = 注册仓单净变化；某日注册仓单为 0（无注册）时 rc 置 NaN 不参与（防除零/假突破）；严禁混入注销仓单总量 |

## 六、频率预算 / 数据准备（冻结前必做，下一步）

1. **拉数**：akshare 拉四大交易所仓单日报历史，验证起止年份与字段（注册/注销是否分列）。
2. **聚合**：映射到品种级日度「注册仓单总量」，跨交割库求和；按交易日历前向填充缺口。
3. **解析计算**：算 rc，统计 IS 候选窗（2019-2021）各品种触发笔数。
4. **判定**：合计 ≥ 10 且覆盖 ≥ 5/9 品种 → 冻结进引擎；否则收档（不调参）。
   ⚠️ 2026-10-22 补：**该判定不完备**，还须加一条「不得常开」——单品种触发天数占比过高（本因子 MA 75.9% / RB 88.1% / SA 83.1% / SR 64.1%）即「无选择性 = 无信息」。此条当时未写成判据，靠人工裁决补上；若日后复活本因子，**必须先把这条写进 gate 再跑**（见 §五 判定标准与 `频率预算.py` 的 ⚠️ 分支）。
