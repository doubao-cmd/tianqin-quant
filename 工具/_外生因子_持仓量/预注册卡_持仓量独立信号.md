# 预注册假设卡 · 持仓量变化（OI-Flow）独立信号

> 创建：2026-09-28　状态：**已注册，未运行**
> 性质：全新单一假设（与双均线无关），K = 1，预注册前向窗只看一次

---

## 0. 为什么是它（而不是库存/基差）
- tqsdk 原生只给价/量/**持仓量**，没有库存/基差/开工。
- **持仓量变化（open_interest 差分）是天然“外生于价格”的变量**——它反映的是“谁在进场、钱往哪边押”，价格序列里读不到。
- 零新数据源、零 K 数据源风险，是最干净的试验田。

## 1. 机制假说（先写逻辑，再测；非“我发现它相关”）
期货持仓量上升 = 新资金入场建仓。
- **OI 上升 + 价格同向** → 新钱在顺势押注（多头建仓推动涨 / 空头建仓推动跌）→ 惯性延续，跟。
- **OI 持平或下降** → 无新钱、或在平仓了结 → 趋势缺燃料、易衰竭 → 离场观望。
这是“资金确认”逻辑，不是价格形态复制，所以算外生信号，不是双均线的 filter。

## 2. 信号规则（写死，非寻优；全部用经验定值）
- 周期：与双均线同尺度 **30min**。
- 回看窗 `LOOK = 20` 根（≈1.5 交易日）。
- `oi_flow = OI[t] - OI[t-LOOK]`（净持仓变动，合约手数）。
- `ret = close[t] - close[t-LOOK]`。
- **开仓条件**（同时满足）：
  1. `oi_flow > 0`（有新钱进场）；
  2. `ret > 0` → 做多；`ret < 0` → 做空。
- **平仓条件**（任一）：
  1. `oi_flow <= 0`（资金流逆转，离场）；
  2. 持仓达 `MAX_HOLD = 40` 根（≈1 日，防耗死）；
  3. 反向信号（多翻空 / 空翻多）。
- **不开仓**：`oi_flow <= 0` 时全程空仓。
- 手数：沿用系统波动率预算（RISK_PCT 1.00% × 20万），与双均线一致，保证可比。
- **不叠加、不加仓、不调参**。

## 4. 事前判定线（MDES，K=1）
- K=1 ⇒ t 退化为 1.96（双侧 5%）。
- `MDES = 1.96 / √T = 1.96 / √3.0 = 1.13`。
- 检验统计量：**9 品种等权平均夏普**（单一统计量，K=1）。
- **PASS（有 edge 证据）**：平均夏普 > 1.13 **且** 正夏普品种 ≥ 5/9。
- **FAIL（支持 H0：无 edge）**：不满足上式。
- 注：平均夏普显著为负 ⇒ 不仅无 edge，且方向相反（逻辑错），直接否决。
