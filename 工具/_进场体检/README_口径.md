# 进场体检 · 口径说明（冻结文档）

> 建于 2026-10-12。**用途：在写任何策略代码之前，先判一个「进场信号」值不值得做。**
> 建立原因：06 MA13 的**毛利只有成本的 4.5%**（README §七之二 结论⑤）⇒ 出场怎么改都没用，
> 瓶颈在**进场**；且 62% 的单子被止损直接扫掉 ⇒ 进场后价格常立刻反向。

---

## 一、为什么要这个工具

过去的顺序是：立卡 → 写引擎 → 单元测试 → 跑 → 发现是负的。
本工具把「**这个进场信号有没有毛利**」提前到**最后一步之前**，成本几乎为零（纯 numpy、秒级）:
```
候选进场信号 ──► L0/L1 体检 ──► 过不了「量级门槛」直接判死，不写一行策略代码
```

---

## 二、三层口径（跑前定死，不许改）

| 层 | 做什么 | 回答什么问题 |
|---|---|---|
| **L0 纯进场** | 进场后**固定持有期**的前瞻毛收益（点/手），**完全无止损** | 信号**有没有方向信息**（无出场逻辑污染）|
| **L1 进场+固定止损** | 进场 + **2×ATR** 止损；到期未止损则持有期满平仓 | 这个小系统**成本后能不能活** |
| **量级判据** | `L1 毛均 ÷ 往返成本（点）` | 离打平**差几倍** |

---

## 三、冻结参数（★ 不许扫、不许调）

| 参数 | 值 | 依据 |
|---|---|---|
| `HOLD` | **12 根**（5min ≈ 1 小时）| 外生定死。**扫描持有期 = 调参（规则 2/4）** |
| `STOP_ATR_MULT` | **2.0**（2×ATR）| 与 06 的兜底止损同倍数；外生定死 |
| `SLIP` | 1 跳 | 与全项目一致 |
| 手数 | **固定 1 手** | 体检用点数计，避开「波动率预算」这个混杂变量 |
| `MA_N/SLOPE_N/ATR_N` | 13 / 5 / 14 | 与 06 同口径（基准锚可比） |
| `BREAK_N` / `TSMOM_N` | 20 / 20 | 经典外生值（唐奇安 System 1、TSMOM 常用档） |
| `RETRACE_TOL` | 0.5 | 与 06 同 |

**成本（点/手，往返）** = `2 × (SLIP×一跳 + 佣金 ÷ 乘数)`，取自 `config_symbols`。
已自检（5 品种全部吻合）：JM 1.3033 / M 2.3000 / JD 3.1604 / P 2.5000 / SR 2.4000。

## 四、通过门槛（★ 五条全过，才算「值得进 full backtest」）

| # | 门槛 | 说明 |
|---|---|---|
| ① | 样本量 `n ≥ 30` 笔 | 少了没有统计意义 |
| ② | **量级** `L1 毛均 ÷ 成本 ≥ 2.0` | 留 1 倍余量给估计误差 / 滑点恶化 |
| ③ | 成本后 `L1 净均 > 0` | 净的，不是毛的 |
| ④ | 显著性 `|t| ≥ 2.0`（**按笔**，不是按 bar）| 按 bar 算 t 会虚高到不可信 |
| ⑤ | **一致性** ≥ ⌈品种数/2⌉ 个品种同时满足 ②③ | 靠单品种拉动的不算 |

---

## 五、⚠️⚠️ 两条纪律（本工具存在的意义就是它们）

1. **本工具只能「判死」，不能「判生」。**
   数据窗口 2021-2023 **已被污染**（06 三段都跑过）。因此任何「✅」**都不构成 edge 证据**，
   只说明「值得进入下一轮、且**必须换干净样本**再验」。

2. **禁止把「批次里表现最好的那个」当成发现。**
   批量跑 N 个信号 = **N 次比较**；挑最好的宣称有效就是过拟合（规则 2 禁区）。
   批量模式（`--all`）**只用于一次性砍掉一批候选**；任何幸存者必须**单独再过一遍预注册卡 + 独立样本**。

---

## 六、禁未来函数

- 信号只用 **≤ 第 i 根已收盘 bar** 的数据；**进场在 `open[i+1]`**。
- 内置「**截断检验**」`--selftest`：对随机抽样，用 `data[:i+1]` 重算 `sig[i]`，
  必须与全量结果**逐一相等**——不等即为未来函数。
- 所有滚动窗口均**不含当前根**（`rolling(...).shift(1)` / `mean(x[i-n:i])`）。

---

## 七、用法

```bash
# 1) 先建数据缓存（12 品种 × 5min × 2021-2023，约 30 分钟；之后所有信号复用同一份数据）
python 工具/_进场体检/拉数据.py

# 2) 未来函数截断检验（改过信号函数就跑一遍）
python 工具/_进场体检/进场体检.py --selftest

# 3) 测单个信号（推荐路径）
python 工具/_进场体检/进场体检.py --signal retrace_ma13

# 4) 批量证伪（结果不可用于择优）
python 工具/_进场体检/进场体检.py --all

# 5) 附持有期诊断曲线（⚠️ 仅供看 edge 衰减形状，**严禁据此择优**）
python 工具/_进场体检/进场体检.py --signal tsmom_20 --diag
```

## 八、内置候选信号（全部外生/经典给定，参数不扫）

| 名 | 说明 |
|---|---|
| `retrace_ma13` | **基准锚** = 06 MA13 的**进场条件本身**（回踩 MA13 + 斜率定方向）|
| `cross_ma13` | 收盘上/下穿 MA13 |
| `breakout_20` | 唐奇安 20 根区间突破（轨道不含当前根）|
| `tsmom_20` | 过去 20 根收益的符号（时序动量）|
| `rev_2bar` | 连续 2 根同向 → 反向开（逆势）|
| `vol_break` | 单根振幅 > 2×ATR 顺势跟进 |

## 九、怎么加一个新候选

在 `进场体检.py` 的 `SIGNALS` 里加一个纯函数：

```python
def _s_my_signal(o, h, l, c, atr, ma):
    # 只允许用「截至当前根」的数据；返回 1.0(多) / -1.0(空) / 0.0(不动)
    ...
SIGNALS["my_signal"] = ("一句话说明 + 经济逻辑", _s_my_signal)
```

加完**必须**跑 `--selftest`。参数一律写死在函数里或顶部常量区，**不许做成可扫描的**。
