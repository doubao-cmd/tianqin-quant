## 五、与 5min 对照：降频到底有没有把毛/成本推上去（机制验证）

> 先验预期：15min 持有时长 ×3 ⇒ 单笔毛位移 ≈ √3 倍、成本不变 ⇒ 毛/成本 ≈ 1.73 倍。
> 检验方式：**同一个 `screen_one`、同一个 2021-01-01~2023-12-31 窗口**，只在 5min / 15min 两套数据上各跑一遍。

| 指标 | 值 |
|---|---|
| 可比格（两边 n≥100） | **283** |
| 5min 毛/成本 中位 | **0.043** |
| 15min 毛/成本 中位 | **-0.059** |
| 逐格差值 中位（15min − 5min） | **-0.078** |
| 15min 更好的格 | **124 / 283** |
| 两边都 >0 的格 | 88，其中 15min 更好 **74** |
| Spearman 秩相关（排序是否稳定） | 0.319 |
| **L0 毛（无止损，同持 12 根）中位：5min / 15min** | **-0.011 / -0.124** |
| L0 毛 逐格差 中位 | -0.024 |
| L0 毛 15min 更大的格 | 139 / 283 |

**⇒ 先验的 √3 没有兑现**（毛/成本中位差 ≈ 0、一半格子变差）。
拆解：连**不含止损**的 L0 毛都没有按 √3 放大（上表），说明问题不在止损，
而在「15min 的 3 小时持有并没有换来 3 小时的价格位移」——两个候选解释都未拆开：
①进场价用**下一根 bar 的 open**，执行延迟从 5 分钟变 15 分钟；
②这类反转/择时信号的有效窗口本来就短于 3 小时，后 2 小时只加噪声。**两者本次未区分**。
