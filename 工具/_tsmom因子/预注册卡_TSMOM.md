**经济解释**：2017-2018 是商品市场的**震荡转折期**（2016 供给侧大涨后的回落与区间震荡）
—— 这正是文献里的 **momentum crash** 形态：12 月动量在 2016 底追多 → 2017 回落；
2017 底转空 → 2018 反复打脸。TSMOM 的亏不是实现 bug（前两版 bug 修复后
硬校验全过），是信号在该 regime 下系统性反向。

**过程中抓到并修掉的 3 个实现 bug**（如实记录，它们曾产出过假结果）：
1. 全日期用纳秒 int 做 `str(d)[:7]` ⇒ 每根 bar 都成"新月份"⇒ **477 次换仓**（月度应 ~23）
2. 权重未归一：`名义_i = 预算×(1/vol_i)/池数` ⇒ 总名义 ≈ 10 倍杠杆 ⇒ 权益 −201%
3. 方向校验用"最终 pos"比对"历史信号" ⇒ 恒 False

**纪律**：⛔ 不调参救（缩短 LOOKBACK / 加止损 / 换权重方案 = 变相择优）；
⛔ VAL/OOS 不跑；⛔ 252 日动量结论只对 2016-2018 样本负责。
 carry（展期收益）是另一个信号源，若试须**新卡**。

## 一、因子定义

```
动量 mom = close[t−1] / close[t−1−252] − 1        ← 用 t−1 收盘，零未来函数
方向：mom > 0 → 该品种持多头；mom < 0 → 持空头；恰好 = 0 → 空仓（罕见）
```

**为什么可能有效（逻辑构成）**：
1. **反应不足**：新信息（供需、库存、宏观）扩散到价格需要数月，
   过去 12 个月的涨跌在下季度有延续倾向。
2. **资产配置型溢价**：TSMOM 赚的不是"选品种"的钱，是**跨期风险溢价** ——
   对每个品种独立做多强势/做空弱势，等价于给趋势装上凸性。
3. **与截面动量的区别（为什么选它）**：截面动量 2011 年后大幅衰减
   （含 6★ 仓库作者自述），TSMOM 衰减慢得多 —— 它不依赖"品种间相对强弱"，
   只依赖"自身延续"。

## 二、参数（文献标准值，一次定死，不许调）

| 参数 | 值 | 依据 |
|---|---|---|
| `MOM_LOOKBACK` | **252** 交易日 | 文献标准（12 个月）|
| `再平衡` | **月度**（每月第 1 个交易日，用 t−1 收盘判定、t 开盘成交）| 文献标准 |
| `波动率窗口` | **20** 交易日收益 std，年化 | 常用短窗（与 LOOKBACK 独立，不构成嵌套调参）|
| `权重` | **波动率倒数**：`w_i ∝ 1/年化vol_i`，归一后乘以总风险预算 | TSMOM 标配（波动大的品种仓位小）|
| `总风险预算` | **名义敞口 ≤ 权益 × 2 倍**（与 MA13 同风格，跨品种合计）| 沿用本仓口径，非新参数 |
| `手数夹` | **[1, 8]**（每品种）| 沿用 |
| `止损` | **无**（出场只有月度换仓）| 文献标配；加止损属逻辑改动须另立卡 |
| `滑点` | 1 跳 | 沿用 |
| `手续费` | `config_symbols.COST`（元/手/边）| 沿用 |
| **品种池** | **9 个固定**（与截面卡一致）：MA / M / RB / V / JD / JM / P / RU / SR | 沿用 2026-10-10 拍板：换窗口不换品种 |

## 五、硬校验（跑前定死，任一失败结果作废）

| # | 校验 | 判据 |
|---|---|---|
| 1 | 方向一致性 | mom>0 的月份必持多、mom<0 必持空（逐月断言）|
| 2 | 再平衡纪律 | 换仓只发生在每月第一个交易日 |
| 3 | 账目恒等 | `INIT + Σ已实现 + 期末浮盈 == final_equity`（容差 1 元；本策略无中途爆仓退出，恒等式必须精确成立）|
| 4 | 无未来函数 | 信号/权重只用 t−1 及更早；成交用 t 开盘 |
| 5 | 品种数 | ≥ 9 |
| 6 | 样本量 | IS 信号期 ≥ 22 个月度换仓（预热吃掉一段的如实反映）|
| 7 | 权益非负 | 逐日权益 > 0（TSMOM 低频低杠杆，若穿越零说明风控实现错）|
