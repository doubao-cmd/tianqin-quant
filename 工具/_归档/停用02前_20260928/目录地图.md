## 一、我现在要跑回测，点哪里？

**双击根目录的 `跑回测.bat`**（就在本文件旁边）。它会弹出菜单：

```
  【跑回测】
    [1] 选策略 + 选品种 → 跑回测
    [2] 打开 策略/ 目录（也可以进去双击 回测.bat）

  【看东西】
    [3] 目录地图（哪个文件夹放什么）
    [4] 打开 回测结果/ 目录
    [5] 打开 工具/_数据/（取到的行情缓存）

    [0] 退出
```

**也可以不走菜单**，直接进目录双击：

```
策略/04_通道突破/回测/甲醇/回测.bat      ← 双击就跑
策略/01_双均线/模拟盘/豆粕/模拟盘.bat    ← 观察模式：只打印信号、不真下单（全套统一）
策略/01_双均线/模拟盘/豆粕/看台账.bat    ← 看那个品种的模拟盘台账
```

> ⚠️ 同一时间**只跑一个回测**（天勤账户同一时刻只允许一个会话）。
> 上一个窗口跑完再点下一个。


⚠️ **02_均线排列 的 K 线周期在品种之间不一致**（`_档案.md` 第 18 行有记录，**非笔误**）：

**bat 不写日志**（2026-09-27）：信号只打印在黑窗口，`工具/tee_log.py` 与 `运行日志/` 都已移除。

## 三、品种放在哪里？

**没有「品种文件夹」了 —— 12 个品种的参数全部在根目录 `config_symbols.py` 里。**

打开它就能看到 `SYMBOLS`（12 条：中文名 / 天勤主连代码 / 合约乘数 / 最小变动价位）
和 `COST`（12 条：每手手续费）。

```
config_symbols.py
    SYMBOLS = {
        "MA": ("甲醇",   "KQ.m@CZCE.MA",  10, 1),
        ...
        "SR": ("白糖",   "KQ.m@CZCE.SR", 10, 1.0),
    }
```

**这 12 个品种**：

| key | 中文名 | key | 中文名 | key | 中文名 |
|---|---|---|---|---|---|
| V | PVC | EB | 苯乙烯 | SR | 白糖 |
| MA | 甲醇 | JD | 鸡蛋 | P | 棕榈油 |
| SA | 纯碱 | JM | 焦煤 | RU | 天然橡胶 |
| RB | 螺纹钢 | LH | 生猪 | M | 豆粕 |

> **2026-09-27 之前**「加品种 = 加一个 `品种池/<key>.py`」，
> 那个写法连同 `品种池/` 一起收进归档了。现在要加品种，改 `config_symbols.py` 两张表即可。
> （旧的 `品种池/` 若搬回来，`config_symbols.py` 末尾的 `_并入品种池()` 仍会认它，`setdefault` 不覆盖已固化的值。）
