# 解释器修复前_20260927 —— .bat 补丁前原件（186 份）

## 这次修的是什么

**2026-09-27 夜，用户双击 `策略/01_双均线/回测/PVC/回测.bat`，黑窗口一闪就报**
`ModuleNotFoundError: No module named 'tqsdk'`，回测根本没起来、报告自然也没有。

根因是**全部 188 个 .bat 的解释器选择顺序反了**：

```bat
rem 旧写法（错）
set "PY=python"
where python >nul 2>nul || set "PY=%USERPROFILE%\.workbuddy\binaries\python\envs\tqsdk\Scripts\python.exe"
```

它**优先用 PATH 里的 `python`**。而用户机器上的 PATH（Explorer 双击时的那个）是：

```
用户 PATH 首位 = C:\Users\cc\AppData\Local\Programs\Python\Python312\
⇒ python = C:\Users\cc\AppData\Local\Programs\Python\Python312\python.exe
⇒ 这个 Python【没有装 tqsdk】⇒ 一 import 就崩
```

而装了 tqsdk 的那个（`...\envs\tqsdk\Scripts\python.exe`）**根本不在用户 PATH 里**，
只在 AI 工具的 shell 里被临时加过 —— 所以**工具里测着好好的，用户双击却是坏的**。

## 新写法（已打进 188 个 bat）

```bat
set "PY="
set "_VENV_TQ=%USERPROFILE%\.workbuddy\binaries\python\envs\tqsdk\Scripts\python.exe"
for %%P in ("%_VENV_TQ%" python py) do (
  if not defined PY (
    "%%~P" -c "import importlib.util as u, sys; sys.exit(0 if u.find_spec('tqsdk') else 1)" >nul 2>nul
    if not errorlevel 1 set "PY=%%~P"
  )
)
if not defined PY (
  echo  [错误] 没找到装了 tqsdk 的 Python，程序起不来。
  ...
  pause
  exit /b 1
)
```

**依次试候选、真 import 一次 `tqsdk`**，第一个能用的就用；都不行就**打一句人话**再退出，
不再甩一坨 traceback。`工具\回滚.bat` 按它自己的规矩（ASCII ONLY）用的是英文提示。
