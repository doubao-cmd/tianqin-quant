## 一、因子定义

### 核心逻辑：增仓滞涨 = 趋势缺乏新增资金支撑

```
① 持仓量变化：oi_chg = close_oi[t] / close_oi[t-20] - 1
② 价格变化：  px_chg = close[t]   / close[t-20]   - 1
③ 信号：
     oi_chg > +5%  且  px_chg < +1%   → 顶部信号（做空/减仓）
     oi_chg < −5%  且  px_chg > −1%   → 底部信号（做多/加仓）
④ 截面聚合：12 品种各算信号，取「最强的 3 个」→ 持仓
⑤ 平仓：反向信号出现即平仓；或最长持有 20 根 K线
```

### 为什么这个逻辑成立（微观结构解释）

期货是**零和**市场。持仓量增加 = 多空双方同时加仓。
- **价格涨 + 持仓量增** → 新增资金认可，趋势健康
- **持仓量增 + 价格不涨** → 有人在更高价位接货，但价格推不动 ⇒ **多头被困**
- 反之「持仓量减 + 价格跌」⇒ 空头被困

### ★ 关键数据事实（已验证，决定实现方式）

⚠️ **`open_oi` 与 `close_oi` 数值完全相同** —— 天勤只填收盘持仓量。
⇒ 因子**只能用 `close_oi`**；
⇒ 「增仓」定义成 `close_oi` 的变化，**不是**「开仓−平仓」。

## 二、参数（一经验值设定，跑前定死，**不许调**）

| 参数 | 值 | 说明 |
|---|---|---|
| `LOOKBACK` | **20** 根 | 约 1.5 交易日（30min × 20）|
| `OI_THRESH` | **±5%** | 持仓量变化阈值 |
| `PX_THRESH` | **±1%** | 价格变化阈值 |
| `TOP_N` | **3** | 12 品种取信号最强的 3 个 |
| `KSEC` | **1800**（30min）| 持仓量变化慢，周期不能太短 |
| `MAX_HOLD` | **20** 根 | 最长持有 |
| 品种池 | **12 个全用** | MA/M/RB/V/SA/EB/JD/JM/LH/P/RU/SR |

⚠️ **窗口选择理由**（写下来备查）：
- LOOKBACK=20：持仓量是慢变量，太短噪声大（实测持仓量对数变化率均值仅 0.18%/bar）
- OI_THRESH=5%：实测 P99 变化率=1.24%，5% ≈ 4 个标准差事件，不会太频繁
- PX_THRESH=1%：与 5% 持仓量变化配对，构成"明显背离"

## 五、判定标准（★ 跑前定死，四条全过才算有效）

### 主判定：绝对夏普

```
★ PASS = 等权平均夏普 > 1.0  且  正夏普品种 ≥ 2/3
```
- 夏普 = `mean(逐bar收益)/std(逐bar收益) × √(年化bar数)`
- ⛔ **0.8 不算有效**（不如存银行）
- 为什么门槛 1.0 不是 1.96：MDES 按 T=3 年约 1.13，但因子类独立样本没那么多，1.0 是务实底线

### ★ 副判定：必须赢基准（最容易漏）

```
★ 须夏普 > 1.593（同窗口 MA13 的 B 口径等权夏普，2026-01-01~2026-03-01 测得）
```
⇒ 否则面试官会问"那为什么不直接跑 MA13"。

### 成本检验

```
★ 交易成本 < 毛收益的 30%
```

### 多空分离

```
★ 多头腿与空头腿各有正贡献（不是全靠单边赌对）
```
⇒ 若"只做多"也能赚 ⇒ 那是 beta 不是截面 alpha
