# 首发分布解析 与 随机进场对照

> 2026-10-13 建。源于一篇方法论论文《期货日内价格事件的条件概率与短周期交易研究》§5.2 / §6。

## 一句话

把论文的「离散三跳边界 → 吸收马尔可夫链」框架落到本项目真实 5min 数据上，回答：

> **「12 根持有 + 2×ATR 止损」下的 46% 止损率，是策略缺陷，还是几何必然？**

## 三块内容

| 块 | 干什么 | 产出 |
|---|---|---|
| **A 解析递推** | 论文 §5.2 的动态规划（给定 u/d/p0、上/下边界格数、步数，算先止盈/先止损/到期概率） | 复现论文示例；给出现实数据的理论参照 |
| **B 随机进场对照** | 同一套 L1 逻辑，跑「信号触发点」vs「随机进场点」 | **信号相对随机时点的真实增益** |
| **C 边界敏感性** | 扫 (止损倍数 × 持有步数) | 止损率由什么主导 |

## 关键结论（12 品种 × 5min × 2021-2023）

1. **46% 的止损率是参数几何，不是策略缺陷。**
   随机时点进场（无信号）止损率 **0.4823**，信号进场 **0.4636** —— 几乎一样。
   ⇒ 「2ATR 止损 + 12 根持有」这个结构本身就会扫掉约一半单子，**与信号质量无关**。

2. **信号有微弱正价值，但统计上不显著。**
   信号相对随机时点的毛增益 **+0.551 点/笔**，跨品种 **t = +1.76 < 2 ⇒ 不显著**；
   且 **8 正 4 负、符号不一致 = 噪声特征**（与「进场体检」72 组判死同结论）。
   ⇒ 0.551 点 vs 往返成本 2.4 点 ⇒ 信号价值只有成本的 **~23%**。

3. **5min 涨跌完全对称。**
   上行占比 `u/(u+d)` 均值 **0.5005**（12 品种全部落在 0.487~0.508）⇒ 无方向偏差。
   这是「信号层无方向信息」的**独立**数学印证。

## 口径与纪律

- 数据/口径与 `工具/_进场体检/` **完全一致**（同一份 CSV、同一 `_atr/_sma`、同一 L1 逻辑，直接 import 复用）。
- 窗口 2021-2023 **已污染** ⇒ 只能判死、不能判生。
- 本工具只做诊断：**不产出交易规则、不改任何策略参数**（规则 2）。
- 随机种子固定（`SEED = 20261013`）⇒ 结果可复现。

## 已知局限

- 解析模型假设「每步至多 1 格（0.5 ATR）」，但真实 5min bar 有 **63.8%** 的步位移 > 1 格
  ⇒ 解析 p_止损（0.209）系统性**低于**真实（0.463）。解析值只作理论参照，
  **真正的检验是 B 列**（真实 vs 对照）。
- 随机进场对照同时随机化了「时点」与「方向」⇒ 它检验的是**信号整体**的价值，
  不能分离两者各自的贡献。
- 三个数字（0.551 / 1.76 / 8:4）都建立在**已污染窗口**上；它们能判死，不能判生。
