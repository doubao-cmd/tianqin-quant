## 两条方法论（已写进 `01` §3 #26 与 §1.7-bis）

1. **日线跨市场对齐必须先做 lag 扫描。** 首次用 `merge_asof(allow_exact_matches=False)` 多推了一天，相关从 0.507 塌到 0.126 —— 错位一天就能让真信号看起来不存在。
2. **「日内」不等于 `close/open`。** 内盘 `open` 是夜盘 21:00，`close/open` 覆盖夜盘+日盘；外盘的欧美时段（21:00-02:30）正好落在里面 ⇒ 把「与外盘同步的不可交易段」当成「可交易段」，凭空造出 β_day≈0.24 的假信号。改用 5min 切 09:00-15:00 后掉到 0.007。
