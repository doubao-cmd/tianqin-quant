# 组合层风险分配对照报告（单变量：腿数封顶 + 总预算切分）

> 2026-09-27 ｜ 工具 `工具/组合风险分配对照.py` ｜ 引擎 `lib/portfolio.py`

## 一、这是什么（★ 先读，避免误读）

**这是仓位数学的对照实验，不是找 alpha。** 期望是线性的：

```
E[组合] = Σ wᵢ · E[腿ᵢ]        ⇒ 本实验只可能改「方差/回撤」，不可能改「期望符号」
```

目的只有一个：验证 2026-09-26 体检 P3 不通过（组合波动 13.97% ≈ √(9×4.5²)，
**方差相加 = 假组合**）能否用「总预算 ÷ 腿数上限」修好。

- **Q1a 恒等式（硬闸门）**：`已实现毛利 − 总成本 = 已实现净利`（差 ≤1 元，必须精确）。
- **Q1b 量级闸门**：`|净利 − 已实现净利| ≤ Σ|期末净手数| × 保证金 × 3`。
  ⚠️ Q1 的**原写法**（`|净利 − 已实现净利| ≤ 1 元`）跑完被认定为**预注册写错**：
  `净利` 取 TqSim `Account.balance`（含期末浮盈）、`已实现净利` 只算已平仓 ⇒
  两者之差**按构造就是期末浮盈**，只在期末空仓时为 0 ⇒ 原判据等价于
  「要求评估期末必须空仓」。已改正为 Q1a（恒等式）+ Q1b（量级）。
- **Q2 封顶生效**：B 档「拒绝 > 0」且「腿数最大 ≤ K」。
- **Q3 风险更可控**：B 档波动 < A 档，且 B 档回撤 ≤ A 档。
- **Q4 纪律**：不因结果调任何参数。

## 六、Q1 的口径事故（★ 必须留档，别再犯）

**预注册的 Q1 原写法（跑前写死）：`|净利 − 已实现净利| ≤ 1 元`。**
跑完两档都判「未通过」（A 差 +34.347、B 差 −445.653）。

回源码核对（`lib/portfolio.py:271 / 458 / 606-611`）后看清它**从一开始就是错的**：

```
净利        = 期末权益 − 初始资金，权益取的是 TqSim 的 Account.balance  ⇒ 含期末浮盈
已实现净利  = 已实现毛利 − 总成本                                  ⇒ 只算已平仓
⇒ 两者之差 **按构造就等于期末浮动盈亏**，只在「评估期末空仓」时才为 0
⇒ 原 Q1 等价于「要求评估期末必须空仓」—— 那不是容器正确性判据。
```

这与 2026-09-26 组合体检 P3 是**同一类错误：判据对象设错**。
两次都发生在「把账户层面的口径当成策略层面的口径」上。教训：

> **写判据前，先把被比较的两个量各自的定义回到源码抄一遍。**

我原以为可以用「净手数 ×（期末收盘价 − 均价）× 乘数」独立复算残差，
结果 A 档独立算 **+1620**、观测 **+34.35**，**差 1585 元**。
（复核脚本与明细：`工具/_Q1对账复核.py`、`工具/_输出/_Q1对账复核.md`）

对不上的原因（两条，都是**记录缺字段**，不是数字错）：

1. **缺 TqSim 的 `float_profit`**：TqSim 逐日结算，账户侧盯市价是**结算价**、
   基准会被结算重置；而 `归因()` 记的「均价」是**原始开仓价**。
   两把尺子不同 ⇒ 不能直接相减。
2. **成交记录没有时间戳**：`成交` 只有 sym/方向/开平/价/量，
   ⇒ **无法把权益曲线与成交在时间上对齐**，逐日对账无法做。

**结论：残差量级（34.35 / 445.65 元，< 净利的 0.3%）与「1~2 手未平仓」的浮盈同阶，
且随未平仓手数增加而增大，与容器一致；但本轮**没有把它精确闭合**。
容器正确性的**正面证据**是另一条：上一轮 `工具/组合对照.py` 已验过
「组合运行器 vs 引擎 `run_backtest_boll` 逐笔一致 + 毛利/成本/净利三项一字不差」。**
