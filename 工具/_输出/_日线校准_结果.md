## 三、★★ 关键发现：tqsdk 的「年化夏普」含无风险利率 2.5%

`tqsdk/tafunc.py:1478`：

```python
def get_sharp(series, trading_days_of_year=250, r=0.025):
    rf = _get_daily_risk_free(trading_days_of_year, r)
    mean = series.mean(); stddev = _tq_pstdev(series, mu=mean)
    return trading_days_of_year ** (1/2) * (mean - rf) / stddev
```

⇒ `夏普 = √250 × (μ_d − rf)/σ_d`，其中 `rf = 2.5%/250`。于是

```
t = 夏普 × √年数 = √(250T)·μ_d/σ_d  −  √(250T)·rf/σ_d
                    └── 真实 edge ──┘     └─ 与 μ 无关的假象 ─┘
```

★ **第二项只依赖样本长度 T 与波动 σ_d，与 μ 无关** ⇒ **样本越长，「负 t 假象」越大**。
这条会把长样本误读成「机制显著为负」—— 本次踩的就是这个坑。

**逐位验证（PVC）**：`√(250×8.77)=46.83`，`σ_d=9.75e-4`
假象项 = `−46.83 × 1e-4/9.75e-4 = −4.80`；真实项 = `+0.92`；合计 **−3.88** = 工具输出原 t ✓

**修正公式**：`去Rf夏普 = 夏普 × R_年化 / (R_年化 − 0.025)`，`真实 t = 去Rf夏普 × √年数`

## 五、判据判决

| 判据 | 结论 |
|---|---|
| **(a) 仪器层** | ✅ **通过** —— 工具的 t 与手算 `夏普 × √8.77` 逐位一致（−3.87 / −6.54 / −1.33） |
| **(b) 机制层** | ✅ **口径一致、仪器正常** —— 日线 t 分布（+0.30 / 0.55）与 30min 基准（−0.61 / 1.04）**统计上一致**，都落在 N(0,1) 内 |
| **(c) 纪律层** | 结果接受、不重跑。**本次登记 K+1 ⇒ 168**（门槛 t 3.199 → 3.201） |

⇒ ★ **结论：01 双均线（趋势/动量机制）在日线上仍然没有 edge（t ≈ 0）。**
⇒ ★ **但「日线口径」本身健康** —— 仪器正常、量纲正确、与 30min 结论一致。
⇒ 按 §7.12.5 A 第三档 ⇒ **机制 A 否掉，转 B（横截面动量）**。

**品种数为什么是 3**：判据 (b) 是**分布检验**，n 个品种的均值噪音 = `1/√n`
（1 个 1.0 / 3 个 0.58 / 7 个 0.38）。3 个已足以判断「分布是否 ≈ N(0,1)」；
且**只有 V 与 M 能跨周期对照**，加到 7 个只是把噪音从 0.58 降到 0.38，不改变定性结论。

## 六、三条必须记住的边界

1. **Rf 陷阱**：用 tqsdk 的夏普直接乘 √年数，**会凭空造出「随样本长度增长的负 t」**。
   今后一切 t 值必须用**去 Rf 的夏普**。⚠️ 反算法在「年化收益贴近 Rf」时不可信；
   根治办法 = 导出 `equity_curve`（`run_backtest` 内部有 `[(bar_dt, balance)]`，但没返回）自算 —— **列为待办**。
2. **跨周期样本不可比**：30min 的 t 来自 2025-03 之后（被烧区），日线来自 2016~2025。
   两者只能比**分布**，不能比**单一数值**。
3. **本校准测的是特异性，不是灵敏度** —— 它回答「日线口径会不会凭空造 edge」，
   回答不了「样本太短是否制造假阴性」（那需要「30min 上显著为正」的砝码，项目里没有；
   替代 = **未来函数版**，§19 实测 t≈60，建议补做）。
