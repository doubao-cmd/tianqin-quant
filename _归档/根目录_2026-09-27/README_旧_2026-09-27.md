## 三层结构怎么用

**核心思想：策略改一次全部生效，品种加一个全部可用，配对关系集中可查。**

| 想做的事 | 改哪里 |
|---|---|
| 改交易逻辑 | `策略池/布林带.py`（一份逻辑，所有品种同时生效） |
| 加一个新品种 | `品种池/白糖.py`（一个文件）+ 新建对应组合 |
| 换周期/参数跑一遍 | `组合/布林带__V.py` 里改 |
| 做低相关性配对 | 新建两个组合 + `组合/配对__V_M.py` |
| 查某次回测怎么跑的 | `回测记录/<策略>__<品种>/<时间戳>_<样本>/参数.json`（含代码快照指针） |
