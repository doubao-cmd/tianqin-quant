# 组合

> **一个配对 = 一个文件。** 回测 / 模拟盘都从这里进。

---

## 现在有什么

```
组合/
 ├─ 通道突破__MA.py     ★ 当前唯一入口
 │                      = 策略池/通道突破/通道突破.py + 品种池/MA.py
 └─ _说明.md            本文件
```

**`通道突破__MA.py` = 通道突破 × 甲醇（30 分钟 · 固定 1 手）**，就是菜单 `[1]`。

> ⚠️ 它**不使用**旧版那套「手数口径 / 组合预算」—— 它**固定 1 手**。
> **仓位管理是「单策略先跑出正期望」之后的事**，这一轮不掺进来。

---

## 规则

1. 文件名固定格式：`<策略短名>__<品种key>.py`，**双**下划线分隔。
   例：`通道突破__MA.py` = 通道突破策略跑甲醇。
2. 组合文件**只写三件事**：引用哪个策略、引用哪个品种、跑什么参数 / 周期。
3. **加一个组合 = 复制 `通道突破__MA.py`，改三处**：

   | 改哪里 | 改成 |
   |---|---|
   | `_读模块("策略池/通道突破/通道突破.py", ...)` | 你的策略文件 |
   | `_读品种("MA")` + `品种 = {"key": "MA"}` | 你的品种 key |
   | `参数` 里的策略参数 | 你的参数 |

   ⇒ 策略代码、品种配置、回测引擎都**不用动**。

## 施工顺序（自下而上，不跳步）

| 序号 | 做什么 | 前置条件 |
|---|---|---|
| **1** | **单策略跑出正期望** | — | ← ★ 当前在这一步 |
| 2 | 多品种组合容器 | 1 有结果 |
| 3 | 腿数闸门 / 仓位管理 | 2 |

⚠️ **不要为了「组合」而组合。**
`E[组合] = Σ wᵢE[腿ᵢ]` 是恒等式：没有正期望的腿，组合只会把负期望摊平 —— 还是负的。
