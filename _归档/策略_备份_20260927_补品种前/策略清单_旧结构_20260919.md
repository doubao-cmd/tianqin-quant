## 1. 双均线（01）

**方向**：多空双向 ｜ **品种**：5 个全有 ｜ **回测 + 模拟盘**齐全

### 周期

- **PVC = 30 分钟**（v5，2026-09-18 改）
- **甲醇 / 豆粕 / 螺纹钢 / 纯碱 = 5 分钟**
- ⚠️ PVC 只改了周期，**均线没同步放大**（仍是 5/20/60）→ 均线时间跨度变成原来的 6 倍

### 指标

- MA5（快线）、MA20（慢线）、MA60（趋势过滤线）
- 全部为简单移动平均，取「已收盘」那一根的值

### 开平仓条件（5 条）

| # | 条件 | 目标仓位 |
|---|---|---|
| 1 | 金叉（快线上穿慢线）**且** MA20 > MA60 | 做多（持空则反手做多） |
| 2 | 金叉 **且** MA20 ≤ MA60 | 只平空，空仓等待（**不反手**） |
| 3 | 死叉（快线下穿慢线）**且** MA20 < MA60 | 做空（持多则反手做空） |
| 4 | 死叉 **且** MA20 ≥ MA60 | 只平多，空仓等待（**不反手**） |
| 5 | 无交叉 | 维持当前方向 |

**一句话**：交叉只决定「平不平」，MA20 与 MA60 的关系决定「能不能反向开仓」。

### 止损（五品种统一）

- 初始止损 **2×ATR(14)**，基准 = 发出信号那根 K 线的收盘价；触发即平仓，**优先于均线信号**（打掉后当根不再看金叉/死叉）
- **保本关闭**（`BREAKEVEN_ATR = 0`）；不含移动止损 / 跟踪止盈
- ATR 算法：真实波幅的 **14 期简单移动平均**（非 Wilder），开仓那一刻锁定，**持仓期间不漂移**、线固定不动

### 仓位（五品种统一：波动率预算）

- `手数 = round(权益 × 1% ÷ (ATR_STOP_MULT × 信号根ATR × 合约乘数))`，夹在 `[1, 8]`
- 权益固定按 **20 万**算（不随盈亏滚动）；每个信号开仓时算一次并**锁定**（不加仓、不递减）
- **手数按品种自动缩放**，不是「每次都开 8 手」—— 分母含合约乘数，波动大 / 乘数大的品种开更少：

| 品种 | 手数分布（本次 30~42 笔） | 平均 |
|---|---|---|
| PVC | 8手×17、7×4、6×6、5×1、4×2 | 7.10 |
| 甲醇 | 7×3、6×7、5×10、4×7、3×3、2×2 | **4.81** |
| 豆粕 | 8×30、7×2、6×8、5×2 | 7.43 |
| 螺纹钢 | 8×39（全部顶格） | **8.00** |
| 纯碱 | 8×23、7×7、6×3 | 7.61 |

- ⚠️ **纯杠杆刻度**：收益率/回撤按手数同倍数放大，夏普 / 卡玛不因此改善
- ⚠️ **郑商所（甲醇、纯碱）有「最小开仓手数」限制** —— 实测甲醇 MA605 上 2 手单被拒 5 次（限价开仓最少 8 手），实盘前需专门验证

### 其他

- `pass_dir=True`（目标仓位式，允许「只平仓、不反手」）
- `ma_filter=60`（MA60 闸门）
- `atr_period=14`

## 2. 均线排列（02）

**方向**：**仅做多**（永不返回 −1） ｜ **品种**：5 个全有 ｜ **回测 + 模拟盘**齐全

### 周期

- **PVC = 30 分钟**（v0，2026-09-19 改）
- **甲醇 / 豆粕 / 螺纹钢 / 纯碱 = 15 分钟**
- 均线、MACD 参数都没动

### 指标

- 四根均线：**MA5 / MA10 / MA20 / MA40**（短 → 长）
- **MACD(8, 17, 9)**，取 DIF / DEA
- 全部取「已收盘」那一根的值

### 开平仓条件（3 条）

| # | 条件 | 动作 |
|---|---|---|
| 1 | 空仓时：`MA5 > MA10 > MA20 > MA40`（多头排列）**且** `DIF > 0` **且** `DEA > 0` **且** DIF 上穿 DEA（水上金叉） | 开多 |
| 2 | 持多时：DIF 下穿 DEA（死叉） | 平多 |
| 3 | 其余情况 | 空仓观望 |

### 止损 / 止盈

- **无**。`STOP_PCT=0` 关闭百分比止损；引擎的动态 ATR 止损因 `atr_stop_mult=0` **整体未启用**（默认值里的 `breakeven_atr=2.0` 不生效）
- 出场**只有 MACD 死叉**这一条路

### 仓位

- **固定 1 手**（无波动率预算）

## 3. 布林带（03）

**方向**：多空双向 ｜ **品种**：5 个全有 ｜ **回测 + 模拟盘**齐全

### 周期

- **全部 5 分钟**（5 个品种统一）

### 指标

- **BOLL(20, 2.0)**：中轨 = MA20，上/下轨 = 中轨 ± 2×标准差
- 标准差用**样本标准差（ddof=1）**，与国内行情软件 STD 口径一致

### 开平仓条件（6 条）

| # | 条件 | 动作 |
|---|---|---|
| 1 | 空仓 **且** 收盘价 ≤ 下轨 | 开多 |
| 2 | 空仓 **且** 收盘价 ≥ 上轨 | 开空 |
| 3 | 持多 **且** 收盘价 ≥ 中轨 | 平多 |
| 4 | 持空 **且** 收盘价 ≤ 中轨 | 平空 |
| 5 | 硬止损：多单收盘 < 下轨×0.98 ／ 空单收盘 > 上轨×1.02 | 平仓 |
| 6 | 优先级 | **先出场、再开仓**；同一根 K 线**不反手**、不锁仓 |

### 仓位 / 止损

- **固定 1 手**
- 唯一止损 = 上面的第 5 条（`STOP_PCT = 0.02`）；无 ATR 止损、无保本、无移动止损

## 4. 通道突破（04）· v0 → v4（2026-09-20；**四个版本全部被回测否定**）

**方向**：多空双向 ｜ **品种**：**仅 PVC** ｜ **回测**齐全（v0/v1/v3/v4 已跑），**模拟盘未建**
｜ **当前代码 = v2 的参数 + 完整版海龟开关**（SYSTEM = "1"：20/10 + failsafe；改 "2" = 55/20 无过滤）

> **结论（结论 39 + 40）**：v0（20/10 无过滤）**−10.87%** ｜ v1（加 MA20/MA60 闸门）**−10.40%**
> ｜ **v3（20/10 + 海龟 failsafe）−12.38%** ｜ **v4（55/20 无过滤）−1.76%**（⚠️ 含 5.92pp 末笔浮盈，
> 已实现 = **−7.68%**），对照 01 双均线 v6 **+1.80%**（同周期 · 同区间 · 同口径、零浮盈）。
> **04 通道突破已判定不成立；海龟的两个系统也都不成立。**

> ⚠️ **读 04 的收益率前必看（结论 40）**：`tqsdk_stat.balance` 是**动态权益、含浮盈** ——
> 回测结束那天手上未平仓的持仓会美化收益率。04 三个版本在 09-13 时都还持有多单
> （末笔浮盈 v0 +1,740 / v3 +425 / **v4 +11,830**），**只有 01 恰好零未平仓**（开仓 213 手 = 平仓 213 手，
> 已用 FIFO 对账逐字吻合）。**跨版本比收益率必须先扣掉末笔浮盈。**

### 周期

- **PVC = 30 分钟**（与 01 双均线 PVC 一致 —— 唯一变量才是「信号源」）

### 指标

- **通道（唐奇安）**：只用过去的最高价 / 最低价，**不用任何均线**
  - 入场轨道：前 **N1 = 20** 根 K 线的最高价 / 最低价
  - 出场轨道：前 **N2 = 10** 根 K 线的最高价 / 最低价
- 两个长度是**海龟交易法 System 1 的原版参数**（外生给定），不扫描（规则2）

### 开平仓条件（4 条）

| # | 条件 | 目标仓位 |
|---|---|---|
| 1 | 空仓 **且** 收盘价 > 前 N1 根最高 | 做多 |
| 2 | 空仓 **且** 收盘价 < 前 N1 根最低 | 做空 |
| 3 | 持多 **且** 收盘价 < 前 N2 根最低 | 平多（**空仓等待，不反手**） |
| 4 | 持空 **且** 收盘价 > 前 N2 根最高 | 平空（**空仓等待，不反手**） |

**一句话**：N1 决定「要不要进场」，N2 决定「要不要离场」—— 两条独立规则。

### 关键口径

- **轨道一律 `shift(1)`**：取「前 N 根」极值、**不含当前根**。少了它就是把本根极值算进轨道 = 未来函数（有断言守着：`工具/_输出/_04验收_0920.py` 的【E】段）
- **用收盘价确认，不用盘中触价**：同一根 K 线里 high 与 low 谁先到，回测层看不到先后，触价会出现「先止损还是先开仓」的歧义。代价 = 比原版唐奇安晚约 1 根，属有意的口径选择
- **出场不反手**：N1 / N2 是两个独立参数、对应两条独立规则；若跌破出场轨道就反手，出场轨道实际变成「反手轨道」，事后说不清哪条在起作用。副作用 = 会出现较长空仓期
- 轨道为 NaN（预热不足）时一律**不开仓、也不误平**（判正不判负，吸取结论 5「NaN 静默失效」的教训）

### 止损 / 仓位（全部套用 01 PVC，逐字一致）

- 初始止损 **2×ATR(14)**，基准 = 信号根收盘价，**固定线不移动**；保本关闭
- 波动率预算手数：`手数 = round(20万 × 1% ÷ (2×ATR×5))`，夹在 `[1, 8]`
- `slip_ticks=1`（等效 2 跳）、`pass_dir=True`、20 万账户、同区间 2026-03-13~09-13

### 版本与过滤

- **v0（基线）**：不含任何过滤（`ma_filter=0`）

  - 04 脚本：`GATE_FAST = 20`、`ma_filter = 60`
  - 语义：只在「空仓要开新仓」时拦 —— MA20 > MA60 才许做多、MA20 < MA60 才许做空；**平仓一律放行**

### ★ 判定与遗留

- **判定：v0 / v1 / v3 / v4 四版均不成立**（不采纳、不新增实验）。已关闭方向：调 N1/N2、调止损宽度、换过滤条件
- ★★ **统一机制（结论 40 的核心）**：**两种原理完全不同的过滤器，在同一套数据上都做成了反向筛选** ——
  v1 是「趋势闸门」（用 MA 关系预判方向），v3 是「结果反馈过滤」（用上一笔盈亏决定跳不跳），
  两者都精确地拦掉了 v0 最大的两笔（+12,680 / +7,240）。⇒ **问题不在「用哪种过滤」，而在「通道突破的信号本身没有正毛利」。**
  深层解释：这套数据里利润集中在**罕见但连续**的趋势延续信号上；任何「减少交易」的机制都会系统性地
  保留「常见但孤立」的震荡信号、剔除连续突破 ⇒ **过滤越强，结果越差**
- ★ **方法论（可复用，结论 39）**：一条在 A 信号源上被验证有效的规则，**不能假定它在 B 信号源上同样有效** ——
  MA20/MA60 闸门在双均线上贡献 92%（结论 19），搬到通道突破上却成了**反向筛选**。
  「搬用已验证规则」本身也要当成一次单变量实验来验证，不能当作免费的先验
- ★★ **口径铁律（结论 40，新增）**：`tqsdk_stat.balance` = **动态权益（含浮盈）**。回测结束那天手上
  未平仓的持仓会**美化收益率** —— 04 的 v0/v3/v4 分别带 +1,740 / +425 / **+11,830** 元的末笔浮盈，
  而 01 恰好零未平仓（开仓 213 手 = 平仓 213 手，FIFO 对账逐字吻合）。
  ⇒ **跨版本比收益率，先扣掉末笔浮盈**；或统一在最后一根强制平仓
- ⚠️ 机制（事后推测）：双均线里信号与闸门**共用同一条 MA20**，是自洽的顺势结构；通道突破里
  「破 20 根高点」时 MA20 通常已 > MA60，闸门拦不到顺势多头，只拦得到**下跌途中的反转突破**，
  而这批在 PVC 上是赚的 ⇒「突破后动量」与「趋势延续」是两套相反假设

## 6. 模拟盘运行记录与台账（2026-09-20 新增）

**为什么要有它**：回测有报告，模拟盘以前什么都没有。而模拟盘要解决一个回测解决不了的问题 ——
「这段时间没交易，到底是**程序没开**，还是**程序开着但条件不够**？」

**机制**：`run_live` 每 5 分钟往 CSV 写一行「运行心跳」，**休市照写**。于是
- 心跳出现**时间断层** → 只可能是**程序当时没在跑**（停机 / 关机 / 崩溃）
- 心跳**连续**却没有 `SIGNAL` 行 → **程序在跑、条件不够**

两者由此完全分开。再加一条判据分辨「停机有没有代价」：断层前后的 K 线时间若
**未推进** → 当时根本没有新 K 线收盘 → **不会漏信号**；推进了 → 可能漏掉信号（台账会标出来）。

**落盘**（`RECORD_DIR`，5 个品种各一套，追加写、utf-8-sig + CRLF，Excel 可直接打开）：

```
实测记录/01_双均线/<品种>/
    <品种>_成交流水.csv    START / SIGNAL / FILL / STOPLOSS / STOP
    <品种>_运行心跳.csv    每 5 分钟一行（休市照写）
    <品种>_双均线_台账.html  ← 一份、路径固定、每次覆盖更新
```

- `RECORD_HEARTBEAT_SEC = 300`（心跳间隔）；把 `RECORD_DIR` 改成 `None` 即完全关闭记录
- 记录**只落盘、不参与任何交易判断**；写盘失败会打印警告但绝不影响交易

**看台账**：双击 `策略/01_双均线/模拟盘/<品种>/看台账.bat`（或 `python 工具/模拟盘台账.py V`）。
台账按月分组，含：运行与空洞（含每段断层的含义）、月度台账、逐笔台账、
**实测滑点**（回测给不了的数字）、**信号-成交核对**（有没有被交易所挡掉）。
**有意不做**：收益率 / 回撤曲线 / 夏普 / 卡玛 —— 笔数少时这些指标没有意义。

**日志**：`运行日志/01_双均线/模拟盘/<品种>/模拟盘日志.txt`（人看的流水，与上面结构化的 CSV 是两回事）。
