## 三个阶段的定位（一句话版）

| 阶段 | 它回答的问题 | 谁是裁判 |
|---|---|---|
| 回测 | 逻辑在历史里有没有正期望 | 数据（但输入假设要真） |
| 模拟盘 | 我假设的滑点/费率/成交在真实盘口成不成立 | **真实盘口** |
| 实盘 | 我能不能在扣掉真实摩擦后长期活着 | 真实账户 |

**核心认知**：回测已经反复证明「1 跳滑点 + 万1 佣金」下策略很漂亮（夏普 4~5），
但 slip3 压测掉到 1.23 —— 结论是**我们的卓越性是假设买来的，不是策略本身**。
所以从回测到实盘，唯一必须信的是模拟盘量出来的真实滑点与费率。

## 阶段 0 · 回测侧补全（实盘门禁，不是模拟盘门禁）

- [ ] **0.1 费率模型升级**：COST 表改为「开仓 / 平今」双费率，按品种查证历史费率。
      已知事实：JM 日内万1.4(2021-05) → 万6(2021-09 近月) → 万3(2023-05 至今)。
      做法：先做**分段常数**（按年份切换），不做逐日精确（工程量不值）。
- [ ] **0.2 涨跌停成交规则**：止损单遇封板不成交、顺延下一根（当前是照常成交）。
      预期影响有限（诊断发现最大回撤不在跌停段），但亏损方向的交易确实要吃。
- [ ] **0.3 slip3 压测写进常规流程**：以后每次策略体检默认带一档 3 跳成本压测，
      与 1 跳同窗对比。**夏普掉下 2.03 = 策略不能进实盘**（这条当准入门槛）。
- [ ] **0.4 组合压测（可选，诊断用）**：slip3 + 平今万6 同时上，看最坏情形。

## 阶段 2 · 小资金实盘（门禁全过才开）

**准入门槛（缺一不可）**
- [ ] 模拟盘观察期 1.6 全部达标
- [ ] 阶段 0 的 0.1/0.3 完成：费率按真实口径建模、slip3 压测下夏普 ≥ 2.03
- [ ] 熔断演练 1.2 通过
- [ ] 长假敞口减半/清零规则已写入日历（SOP 已有，执行一次验证）

**开工前必做的三件人工事**
- [ ] **2.1 找期货公司要真实费率表**：逐品种「开仓 / 平今 / 平昨」三个数，
      外加「是否交易所+1% 手续费」——这决定实盘能不能活。
- [ ] **2.2 下单参数定死**：限价 or 市价（建议限价+超时撤单重挂）、追单策略、
      断线后持仓一致性核对流程。原则：**宁可少成交，不要错持仓**。
- [ ] **2.3 品种只上 1 个**：优先名义杠杆低的（EB / P 一类），把「名义敞口 ≤2倍」这条
      在真实资金上再验一次；焦煤名义最重（4 倍）放到最后。

**实盘与模拟盘的 5 个真实差异（只列会咬人的）**
1. 费率按**你的实际费率**，不是交易所基准
2. 平今单列收费（回测已按此建模，实盘要核对）
3. 封板时止损单排不上队，回测当前是照常成交 ⇒ 实盘可能更痛
4. 部分成交 / 撤单排队真实存在
5. 重连后持仓状态可能与本地不一致（必须核对，不信任内存）
