## 一句话逻辑

**价格跌破布林带下轨就买、涨破上轨就卖，回到中轨平仓。**

**均值回归**型 —— 赌「偏离太远会拉回来」。双向。

## 定稿参数（v4）

| 项 | 值 |
|---|---|
| 周期 | **30 分钟** |
| 指标 | **BOLL(20, 2.0σ)**：中轨 = MA20，上下轨 = 中轨 ± 2×标准差（样本标准差 ddof=1） |
| 开仓 | 空仓 且 收盘 ≤ 下轨 → 开多；空仓 且 收盘 ≥ 上轨 → 开空 |
| 出场 | v1 起改为：**回到中轨另一侧 0.5×半带宽**（不是碰中轨就走） |
| 时间止损 | v2 起：**满 20 根未出场即离场** |
| 硬止损 | v3 起收窄为 **1×ATR**（原 2×ATR） |
| 仓位 | v4：基数 **40 万**、`RISK_PCT 0.30%`（账户 100 万里锁死 60 万不动） |

## ★ 最重要的一条：那个 +10.42% 不能当证据

`PVC_布林带.json` 里 v3 = **+10.42%**，是五个策略在整个 2026 上半年**唯一的正收益**。

但它是这么来的：

```
v0  +2.09%  （裸版）
v1  +2.60%  （出场改「中轨另一侧0.5×半带宽」）
v2  +3.31%  （加时间止损 20 根）
v3 +10.42%  （止损 2×ATR → 1×ATR）
```

**一路在同一个 2026 样本上改，越改越好 —— 这叫过拟合。**

三条硬证据：

1. **2026 IS 是全历史唯一正窗口**（09-22 原话）。
2. +10.42% 由「止损 2.0→1.0」这一**择优动作**取得 ⇒ **不得当 alpha 证据**。
3. 止损收窄后手数自动翻倍（单笔风险仍锁 1%），是**杠杆放大**，不是策略变好。

⇒ 正确理解：**03 定死在震荡区间勉强保本、趋势行情反复逆势亏损。**
2026 是它碰巧对上的环境，不是它的本事。
