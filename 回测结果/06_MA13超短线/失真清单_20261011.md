## 二、根因（源码级，已独立复现）

### 2.1 两条记账路径不一致

`策略/06_MA13超短线/回测/<品种>/MA13超短线_回测.py`：

```python
# ── 逐笔记账（第 225 行）── 正确：开仓价 → 平仓价
pnl = pos * (exit_price - entry_price) * MULT - exit_cost

# ── 权益曲线（第 274-275 行）── 用收盘价逐 bar 累加
if pos != 0:
    equity += pos * (close[i] - close[i - 1]) * MULT
```

**关键缺陷**：第 274 行的 `if` **不排除开仓 bar 与平仓 bar**。

- 开仓 bar `p`：`pos` 已在第 255/263 行置为非零 ⇒ 第 275 行把
  `(close[p] - open[p])` 也算进权益，而这笔交易的真实起点是 `open[p]`
- 平仓 bar `q`：`pos` 尚未清零 ⇒ 又算了 `(close[q] - close[q-1])`，
  而真实出场价是 `open[q]`（或止损价）

### 2.2 边界误差公式

```
路径①(权益) − 路径②(逐笔) = Σ s·hand·MULT·[ (close[开仓bar] − open[开仓bar])
                                         + (出场价 − close[平仓bar]) ]
```

> ⚠️ **每手点差均值 ≈ 0（±0.25 点以内）⇒ 策略的「等权期望」≈ 0，扣掉成本后为负。**

## 六、修复方案 —— ✅ **已于 2026-10-11 全部实施**

### 6.1 核心修法 ✅ 已实施

`equity` 改为**只在平仓时变化**（已实现口径），并另存一条 `eq_mark` 镜像用于画图。

```python
# 开仓时：只记录 cur_open_cost，不动 equity
cur_open_cost = oc

# 平仓时：一次性结算（pnl 含双边成本）
pnl = pos * (exit_price - entry_price) * MULT - cur_open_cost - exit_cost
equity += pnl

# 逐 bar（仅供画图/回撤/夏普）：
eq_mark = equity + pos * (close[i] - cur_entry_price) * MULT
```

> ★ 实际实施时比原方案**多修了一处**：原 `pnl` 只扣平仓单边成本
> （`equity -= oc` 另走），这使「逐笔合计 ≠ 权益变动」**永久存在**。
> 现在 `pnl` 含双边成本 ⇒ **Σpnl ≡ Δequity 成为恒等式**。

### 6.2 自动对账断言 ✅ 已实施

```python
_pnl_sum = sum(r["pnl"] for r in trades_rec)
_diff = equity - INIT - _pnl_sum
_tol = max(1.0, len(trades_rec) * 0.01)   # 逐笔 pnl 保留 2 位小数的累计舍入上限
if abs(_diff) > _tol:
    raise AssertionError("记账对账失败：已实现权益 != INIT + 逐笔 pnl 合计")
```

> ★ **容差必须随笔数缩放**：初版固定 1 元，鸡蛋（`COMM=5.802` 非整数）因累计舍入
> −1.53/−1.76 元**误报**。改为 `0.01 元/笔 + 1 元保底` 后无误报。
