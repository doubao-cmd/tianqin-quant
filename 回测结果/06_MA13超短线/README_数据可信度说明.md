## 二、为什么全部作废：止损价 bug

2026-10-08 的 commit `a61c3ae` 修了一处 bug：当跳空低开时，
`max(entry − 2×ATR, swing_low − 0.5×ATR)` 会选中 `swing_low` 支，
使**止损价落到入场价的有利侧** ⇒ 下一根 K 线的 `low ≤ stop` 立刻成立
⇒ 以一个**不存在的价格**平仓，凭空产生盈利。

**逐笔统计证据**（焦煤开发窗 3317 笔，本目录下的 txt）：

| 出场方式 | 笔数 | "盈利"笔 | 胜率 |
|---|---:|---:|---:|
| 时间止损 | 800 | 721 | 90.1% |
| **止损** | 2517 | **845** | **33.6%** ← 止损单不可能盈利 |

修复后同代码重跑：`止损组 0/1773 = 0.00%`（硬校验通过）。

⚠️★ **硬校验规则：止损组胜率必须恒为 0.0%。见到非 0 ⇒ 这份产物作废。**

### 本目录下产物里能直接看出这个 bug 的三个

## 五、怎么判断一份产物能不能用（三关全过才能引用）

### 第1 关：看 `cost_assumption` 字段

```bash
python -c "import json;d=json.load(open('某份_参数.json',encoding='utf-8'));print(d['cost_assumption'])"
```

判读规则：

| 特征串 | 含义 | 可用? |
|---|---|---|
| `当前权益` | 复利口径 | ❌ 与模拟盘不对账 |
| `利润满40万` | 阶梯加仓（已废弃） | ❌ |
| `名义敞口` | 有名义夹 | 需看手数口径 |
| `目标风险2000` | 老口径（未复利未夹） | 口径✅ 但仍是 bug 版本 ❌ |

⚠️ **目前没有任何一份含`GAP_FILL` 标记** ⇒ 全部是理想价成交口径。
