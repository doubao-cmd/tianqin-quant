## 目录约定

```
回测结果/
    <编号>_<策略名>/                 01_双均线 / 02_均线排列 / 03_均值回归 / 04_通道突破 / 05_摆动线
        <品种>/                      中文名，如 甲醇 / 豆粕 / 白糖
            <品种>_<策略>_<周期>_<样本>.html        回测报告（资金曲线 + 逐笔 + 指标卡）
            <品种>_<策略>_<周期>_<样本>.txt         逐笔成交明细
            <品种>_<策略>_<周期>_<样本>_参数.json   本次运行的参数快照
            <品种>_<策略>_汇总.html                汇总页（版本倒序，"当前" = 最新那版）
```

例：`回测结果/04_通道突破/甲醇/甲醇_通道突破_30min_is.html`

## 谁往这里写

- `lib/engine.py` 的 `_save_backtest_report()` —— 回测跑完落盘（路径来自 `lib/paths.py`）。
- `工具/汇总报告.py` —— 抓最新报告 → 写账本 `工具/_账本/<品种>_<策略>.json` → 重渲染 `_汇总.html`。
- `工具/回滚.py` —— 把本次报告 / 明细移入回收站（`_汇总` 永不删）。

## 规则

- **只留「当前最新版报告」+「汇总页」**；旧版本 / 往年 / 测试报告**立即走回收站**
  （`lib.recycle.移入回收站`，可还原；禁 `os.remove`/`rmtree`）。
- **OOS 期末考 / 一次性实验 / 跨年对比**等特殊报告，**先问用户**再决定留不留，不擅自删。
- ⚠️ `工具/汇总报告.py` 的 `更新()` 写的是账本**最后一条** ⇒ **必须先补卡、再跑回测**，
  否则新数字会覆盖上一张卡。
