## 一句话逻辑

**收盘价在均线下方就做多、在上方就做空，穿越均线即反手。**

三行讲完：

```
收盘价 < MA(N1)  ->  目标做多（价格低于均值，赌它涨回去）
收盘价 > MA(N1)  ->  目标做空（价格高于均值，赌它跌回去）
穿越均线的瞬间即反手 —— 永远在场，没有空仓状态
```

参数只有 `N1` 一个。没有 σ 通道、没有中性区、没有任何过滤。

## 已知代价（跑之前就该有数）

**永远在场 ⇒ 换手 = 均线穿越次数**，是本项目所有策略里最高的。

- 粗算：30 分钟 K 线 + MA20，一年约 250 个交易日 × 每天 1~2 次穿越 ⇒ **数百次反手**
- 每次反手 = 平旧仓 + 开新仓 = 2 ×（1 跳滑点 + 手续费）
- 参照：05_摆动线是唯一毛利赚钱的策略，成本仍占 62%~91%

⇒ **成本会吃掉相当一部分毛利。这不是意外，正是本轮要测的东西。**
⇒ 判据看 **夏普 / 卡玛 / 单笔期望**，不要只看收益率。
